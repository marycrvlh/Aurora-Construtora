# 🌅 Aurora Construtora

Site institucional e vitrine de empreendimentos para a **Aurora Construtora**, uma construtora fictícia de condomínios de alto padrão em Piracicaba - SP. O projeto apresenta a empresa, seus serviços e dois empreendimentos, com páginas de detalhes, galeria de fotos, vídeo de apresentação e formulário de contato.

> Projeto desenvolvido com HTML, CSS e JavaScript puros, com foco em layout, identidade visual e boas práticas de front-end.

---

## ✨ Funcionalidades

- **Página inicial** com hero, números da empresa, valores (sustentabilidade, confiança e design exclusivo), serviços e projetos em destaque.
- **Páginas de empreendimento** (`project01.html` e `project02.html`) com:
  - galeria de fotos com miniaturas clicáveis que trocam a imagem principal;
  - descrição, diferenciais e card de ficha técnica (status, metragem, quartos, garagem e localização);
  - vídeo de apresentação incorporado do YouTube.
- **Formulário de contato** com campos obrigatórios, validação de e-mail e de telefone no formato `(00) 00000-0000`, e feedback visual ao enviar.
- **Navegação suave** entre seções (`scroll-behavior: smooth`).
- **Interações e animações** em botões, cards e links com `transition` e `:hover`.
- **Paleta própria** definida por variáveis CSS (tons de marrom, areia e terracota).

---

## 🛠️ Tecnologias

- **HTML5** semântico
- **CSS3**: Flexbox, Grid, variáveis CSS, `clamp()`, transições
- **JavaScript (ES6)**: manipulação do DOM e eventos
- **Google Fonts**: Outfit e Inter
- **Unsplash** (fotos das fachadas) e **YouTube** (vídeos incorporados)

---

## 🚀 Como executar

Não há dependências nem etapa de build.

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/aurora-construtora.git

# 2. Entre na pasta
cd aurora-construtora

# 3. Abra o index.html no navegador
```

Se preferir, use a extensão **Live Server** do VS Code para recarregar a página automaticamente.
